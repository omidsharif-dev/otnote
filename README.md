# ot note

A minimal note-taking app built with React Native and TypeScript.

## Features

- Create, edit, and delete notes
- Local persistence with AsyncStorage
- Clean, minimal UI
- TypeScript throughout

## Getting Started

```bash
# Install dependencies
npm install

# Start Metro bundler
npm start

# Run on Android
npm run android
```

## Build APK

```bash
cd android
./gradlew assembleRelease
```

The APK will be at `android/app/build/outputs/apk/release/app-release.apk`
